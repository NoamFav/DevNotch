# Security Policy

DevNotch is a personal fork of [Boring Notch](https://github.com/TheBoredTeam/boring.notch). Vulnerabilities in the core app most likely also affect upstream and are best reported there, via their GitHub Security Advisory ["Report a Vulnerability"](https://github.com/TheBoredTeam/boring.notch/security/advisories/new) tab.

## Reporting a Vulnerability

For issues specific to this fork's own additions (the AeroSpace widget, extra HUD widgets), please use this repository's GitHub Security Advisory "Report a Vulnerability" tab instead.

Report security bugs in third-party dependencies to the person or team maintaining the package or dependency.
